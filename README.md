# Stellar Burgers — космическая бургерная 🍔🚀

SPA-приложение для сборки бургеров и оформления заказа: пользователь выбирает ингредиенты, собирает бургер, авторизуется и проходит полный путь до отправки заказа на сервер.

## Функциональность

- Каталог ингредиентов с получением данных с сервера
- Конструктор бургера с drag-and-drop сборкой
- Оформление и отправка заказа через API
- Авторизация и регистрация пользователя
- Защищённые маршруты (доступны только авторизованным пользователям)
- Роутинг между страницами приложения (лента заказов, профиль, конструктор)

## Стек технологий

React, TypeScript, Redux (глобальный store), React Router, Webpack, Storybook, ESLint/Prettier

## Архитектура

- Работа с сервером и состоянием приложения реализована через Redux: асинхронные запросы, хранение и обновление данных в глобальном store.
- Роутинг настроен с разделением на публичные и защищённые маршруты (доступ к личному кабинету и оформлению заказа — только после авторизации).

## Установка и запуск

```bash
npm install
npm run dev
```

Для работы запросов к серверу добавьте переменную окружения `BURGER_API_URL` (пример — в файле `.env.example`).
